# Kilomarket

## Standing instructions
- After any code change: commit, push to GitHub (`git push origin main`), and deploy to Vercel (`npx vercel --prod --yes`) — always, without asking.
- Run `npm run typecheck` and `npm run build` before pushing.

## Commands
- Typecheck: `npm run typecheck`
- Build: `npm run build`
- Deploy: `npx vercel --prod --yes` (production URL: https://kilomart.vercel.app)
